# الواجهة الجديدة (web/)

صفحة ويب واحدة (HTML + CSS + JS بلا مكتبات) تقرأ من واجهات المرصد الحالية `/api/*` نفسها.

- 19 صفحة: نظرة عامة، الصحة، التوصيات، التنبيهات، المعالج، الذاكرة، الرسوميات، العمليات، WSL، الطاقة، حركة القرص، المساحة، بدء التشغيل، الجدولة، القواعد، السجل، القاعدة، التحكم، المظهر.
- الاتجاه البصري: "لوحة قيادة" رمادية داكنة بلون واحد مميز، أرقام بخط Bahnschrift، سمة فاتحة/داكنة، RTL كامل.
- الإجراءات المسموحة (تأكيد قبل التنفيذ): تبديل القواعد والمهام وعناصر البدء، خطة الطاقة، تنظيف الذاكرة، حدود التنبيه، المظهر، تشغيل مهمة خلفية. التنظيف الفعلي للقرص غير مفعّل هنا عمدًا.

## المعاينة محليًا
`python web/dev_proxy.py 47900` ثم افتح http://127.0.0.1:47900/ — الوكيل يمرّر `/api/*` بالرمز المحلي ويخدم القراءة فقط (الكتابة ترفضها الخادم بسبب فحص Origin).

## التشغيل داخل المرصد
لم يُربط بعد بالخادم: يحتاج مسارًا في server.py (مثلاً `/v2`) وإعادة تشغيل الخادم بصلاحية المسؤول.
