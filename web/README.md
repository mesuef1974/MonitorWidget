# الواجهة الجديدة (web/)

صفحة ويب واحدة (HTML + JS بلا مكتبات) وأنماط مركزية في `web/css/` تقرأ من واجهات المرصد الحالية `/api/*` نفسها.

- 19 صفحة: نظرة عامة، الصحة، التوصيات، التنبيهات، المعالج، الذاكرة، الرسوميات، العمليات، WSL، الطاقة، حركة القرص، المساحة، بدء التشغيل، الجدولة، القواعد، السجل، القاعدة، التحكم، المظهر.
- الاتجاه البصري: "لوحة قيادة" رمادية داكنة بلون واحد مميز، أرقام بخط Bahnschrift، سمة فاتحة/داكنة، RTL كامل.
- الإجراءات المسموحة (تأكيد قبل التنفيذ): تبديل القواعد والمهام وعناصر البدء، خطة الطاقة، تنظيف الذاكرة، حدود التنبيه، المظهر، تشغيل مهمة خلفية. تشمل أيضًا تنظيف المساحة (معاينة ثم تأكيد)، الحجر، تقرير المكرر والكبير، الكانس، تنفيذ طبقات التنظيف، وشرح النموذج المحلي.

## المعاينة محليًا
`python web/dev_proxy.py 47900` ثم افتح http://127.0.0.1:47900/ — الوكيل يمرّر `/api/*` بالرمز المحلي ويخدم القراءة فقط (الكتابة ترفضها الخادم بسبب فحص Origin).

## التشغيل داخل المرصد
يخدمها `server.py` على `/` (وعلى `/v2` اسمًا قديمًا) بالتذكرة والكوكي نفسيهما؛ هي الواجهة الوحيدة بعد إزالة الواجهة القديمة.

## الهوية البصرية المركزية (web/css/)
الأنماط ليست في الصفحة؛ كل شيء في ملفات مرتّبة بالتسلسل نفسه الذي تُحمَّل به:

| الملف | المحتوى |
| --- | --- |
| `tokens.css` | المصدر الوحيد للألوان (داكن/فاتح) والباليتات والخطوط والمسافات والظلال والطبقات. لا لون خارجه |
| `base.css` | إعادة الضبط، الطباعة، شريط التمرير، إمكانية الوصول، تقليل الحركة |
| `layout.css` | الهيكل: الشبكة والقائمة الجانبية والشريط العلوي ونقاط التجاوب |
| `components.css` | المكوّنات: أزرار، بطاقات، مؤشرات، جداول، قوائم، رسوم، نوافذ، رسائل |
| `utilities.css` | فئات صغيرة بدل الأنماط المضمَّنة (`.mono`, `.cell-path`, `.mw-*` …) |

قواعد: لا `<style>` داخل الصفحة، ولا ألوان خام خارج `tokens.css`، ولا نمط مضمَّن إلا لقيمة تأتي من البيانات (عرض نسبي، لون سلسلة). يفحص ذلك `tests/check_all.py`.
يقدّم الخادم الملفات من `/css/<name>.css` بـ ETag دون تخزين طويل، فيظهر أي تعديل فورًا.
