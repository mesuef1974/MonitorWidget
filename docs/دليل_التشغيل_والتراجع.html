بيئة التشغيل

التطبيق مخصص لـWindows ‏64 بت؛ اللوحة HTML وJavaScript محليان، والويدجت WPF يعمل عبر PowerShell 7 في وضع STA. المراقبة الأساسية تستخدم المكتبة القياسية في Python. تعتمد وظائف إضافية على أدوات Windows، وEdge لفتح نافذة التطبيق، وأدوات GPU أو WSL أو Docker عند استخدام تلك الميزات.

أُعدّت بيئة Python ‏3.14.9 المضمنة داخل runtime/python/python314، ومكتبة SQLite ‏3.54.1 داخل runtime/sqlite. لا تعدل هذه الحزمة مفسرات Python أو مكتبات SQLite المثبتة للتطبيقات الأخرى. ثُبتت الحزمتان ببصمتي الأرشيف من المصدر الرسمي، وثُبتت DLL الخاصة بـSQLite ببصمة حرفية في المحمّل.

ملف python314._pth يحصر البحث في المكتبة القياسية والحزمة وجذر التطبيق، دون استيراد site أو مسارات البيئة أو مجلد العمل العشوائي. يجب أن تُحمى البيئة كاملة مع الكود عند تشغيلها بصلاحية مسؤول؛ حماية ملف agent وحده لا تكفي.

فحوص آمنة قبل إعادة التشغيل

من جذر المشروع، يشغّل الأمر الآتي مجموعات الانحدار المعزولة فقط. لا يشغّل تنظيفًا أو يختبر تعديل عناصر بدء التشغيل. مجلدات الاختبار مؤقتة داخل tests/.sandboxes وتُحذف بعد انتهاء الاختبار.

./runtime/python/python314/python.exe -I -X utf8 -B tests/run_all.py --isolated

المجمّع يشمل عقود الخلفية، وحفظ JSON المتزامن، وتهيئة القاعدة، والتاريخ، وتعافي الجدولة، والحجر، وSQLite، وتغطية درجة الصحة، وسلوك JavaScript، وعناصر WPF الأصلية. نجاح هذه الاختبارات لا يثبت مطابقة WCAG أو سلامة كل تكوينات Windows.

فحص الصياغة والربط بين الواجهة والخادم:

./runtime/python/python314/python.exe -I -X utf8 -B tests/check_all.py

قد يكشف هذا الفحص أيضًا تناقضًا في وصف قاعدة تنظيف خارج المشروع؛ لا تُعطّل قاعدة أو تفعّلها لمجرد جعل الفحص أخضر دون فهم الحالة المطلوبة.

تمرين استعادة نسخة إلى بيئة منفصلة مع التهيئة وقراءات الخدمة:

./runtime/python/python314/python.exe -I -X utf8 -B restore_test.py --sandbox-parent tests/.sandboxes

زمن الاستعادة الذي يخرجه التمرين يخص نسخ قاعدة البيانات وقراءات الخدمة المعزولة، لا استعادة Windows والمهام والرموز والحجر بالكامل. عمر أحدث عينة في النسخة مقياس ملاحظ للفجوة الزمنية، وليس هدف RPO معتمدًا.

تشغيل tests/run_all.py دون --isolated يضيف الفحوص الخارجية والحية؛ بعضها يقرأ API قد يحفظ التطبيق أثناءه حالته الطبيعية. لا تستعمل --write إلا عندما يكون اختبار تبديل عنصر بدء تشغيل مقصودًا ومصرحًا به.

رموز الخروج: 0 نجحت التغطية المطلوبة، 1 فشل، و77 تغطية اختيارية غير مكتملة. لا يعدّ غياب المحرك أو السياسة المطلوبة نجاحًا.

درجة الصحة والحداثة

كل مكوّن يملك حالة measured أو missing أو stale مع طابع قياس. البيانات المفقودة أو القديمة لا تحصل على نقاط سلامة. تُعرض التغطية بجانب الدرجة؛ الدرجة الجزئية تستعمل وزن المكونات المقاسة فقط، ولا تقارن بتاريخ الدرجات المكتملة كما لو كان المقام واحدًا.

الحدود الحالية: مسبار العتاد ثماني ساعات (جمع كل ست ساعات مع سماح ساعتين)، والتحديثات 36 ساعة، وحرارة GPU ثلاث دقائق. تصبح الدرجة غير متاحة إذا قل مجموع أوزان المصادر المقاسة عن 50٪. لا يحفظ السجل اليومي الجديد إلا درجة مكتملة؛ الدرجات الأقدم لم تُعد حسابها بأثر رجعي.

«آخر استجابة» في الواجهة تعني وقت استلام جواب API؛ لا تكفي وحدها لإثبات حداثة العينة. مصدر العينة وطابعها وحالة اتصالها يُؤخذ كل منها في الاعتبار. لا تفسّر «غير مقاس» على أنه «سليم».

النسخ والحجر والتعافي

النسخ المحلي يستعمل SQLite Online Backup API، ويتحقق من السلامة قبل اعتماد الملف. تبقى آخر 14 نسخة. للوجهة الخارجية حالة نجاح ومحاولة مستقلة وإعادة محاولة عند الفشل؛ تُقارن بصمات النسخ قبل اعتماد الوجهة. تغيير مكان النسخ لا يغير موقع قاعدة العمل.

الحجر ليس عملية ذرية واحدة تجمع SQLite ونظام الملفات. سجل النية وحالات النقل والاستعادة والحذف يجعلان الانقطاع قابلًا للكشف والتسوية. تُحجز العملية بقفل Windows قبل تغيير الملفات؛ لا تُسحب ملكية عمل حي لمجرد تجاوز مدة زمنية. تُرفض المسارات غير الآمنة والنقل بين الأقراص بدل ادعاء نقله ذريًا.

الملفات التي يفشل تسوية سجلها تظهر بحالة فشل ووصف قابل للمراجعة، دون زر استرجاع مضلل. لا تحذف مجلد الحجر أو تعدّل سجلاته يدويًا أثناء عمل المكونات.

التثبيت المحمي

اختار المالك الإبقاء على صلاحية المسؤول وتجهيز نقل التطبيق إلى تثبيت محمي. تجهيز الحزمة لا يعني أن المهام تحولت إليها أو أن النسخة العاملة أُعيد تشغيلها.

  1. اجمع أدلة المهام والصلاحيات ببنية آمنة من inspect_runtime_20261025.ps1؛ لا تنشر ملف الأدلة لأنه يحتوي مسارات الجهاز.
  2. راجع خطة المثبّت install_protected_app_20261025.ps1 ومعاملاته قبل التنفيذ. المسار المستهدف هو C:\ProgramData\MonitorWidget\app، مع مفسر ومكتبات وأصول محمية.
  3. احمِ ملفات الرموز والبيانات والسجلات والنسخ والحجر بصلاحيات المالك أو المسؤولين وSYSTEM؛ لا تمنحها قراءة عامة لمجموعة Users.
  4. احفظ تعريفات المهام الأصلية، وتحقق من خلو المسارات وسلسلة المجلدات من صلاحية استبدال تسمح بتعديل الكود من مستخدم عادي.
  5. لا تنقل التشغيل أثناء نشاط النسخة القديمة أو تترك نسختين تشتركان في منفذ أو مهمات تنظيف. خذ لقطة نهائية متسقة بعد إيقاف الأعمال، ثم اختبر النسخة المحمية.
  6. تحتاج بوابة التفعيل إلى دليل مرتبط ببصمات المصدر واختبارات واجهة متناسبة؛ أي فحص بصري غير منفذ يظل قيدًا معلنًا.

لا يغير التطبيق سياسات الأمان أو صلاحيات حسابات أخرى لتجاوز مشكلة وصول. إذا احتاج التثبيت صلاحية مسؤول فعلية ولم تتوافر، يُترك جاهزًا للمراجعة ويذكر العائق.

الجلسات والمهل

جلسات المتصفح مستقلة وعشوائية، بمدة افتراضية 12 ساعة مع إلغاء منفرد. إعادة تشغيل الخادم تلغي الجلسات المفتوحة؛ أعد فتح اللوحة بالطريقة المعتادة للحصول على تذكرة جديدة. رمز اتصال الويدجت مستقل عن جلسة المتصفح ولا يظهر في روابط الفتح.

طلبات JSON محدودة الحجم والمهلة والتزامن، وتُرفض الأعداد غير المنتهية. الأوامر المؤثرة لا تعاد تلقائيًا عند فشل النقل لأن التنفيذ قد يكون بدأ. إعادة تأكيد 428 مقيدة بمعاملات الطلب، ولا تعادل إعادة محاولة عمياء.

مهل المجدول تعاونية مع حدود فعلية حيث تدعمها عمليات IO والأوامر الخارجية. لا يُقتل خيط Python قسرًا، ولا يعاد تشغيل عمل ما زال حيًا؛ لذلك لا يوجد وعد بمهلة قسرية لكل استدعاء نظام غير متعاون.

التراجع والقيود

أصول الكود قبل الإصلاح محفوظة في backups/audit_fixes_20261025. الحزمة الأصلية وبياناتها لا تُحذف أثناء تجهيز النقل. لا تنسخ قاعدة قديمة فوق بيانات أحدث دون قرار صريح؛ التراجع عن الكود لا يساوي التراجع عن البيانات.

قبل تراجع يدوي: أوقف المكونات بصورة منسقة، واحفظ نسخة متسقة جديدة من القاعدة والملفات، ثم راجع توافق المخطط. أعمدة الحجر الإضافية توسعة للمخطط؛ قد لا يفهم الكود القديم حالات الانتقال الجديدة. لا تشغّل نسختين مختلفتين تتعاملان مع الحجر أو قاعدة البيانات نفسها.

النوافذ المفتوحة والمهام التلقائية قد تحمل نسخًا مختلفة من الكود حتى يكتمل نقل التشغيل؛ قراءة أو تعديل المصدر لا يثبت ما حملته كل عملية. أثبت مسار التنفيذ والإصدار بعد التفعيل، وسجّل آخر تشغيل للمهام.
