## 4) خطوط حمراء
- لا منظّفات سجل، ولا تعطيل خدمات (Nahimic، SysMain، WSearch، Defender، Windows Update).
- لا /ResetBase، ولا مساس بـ WinSxS أو Prefetch أو Installer أو pagefile أو hiberfil.
- لا حذف في Downloads أو Desktop أو Documents أو مستودعات D: إلا بتقرير ثم تأكيد صريح لكل عنصر.
- لا حذف مرتفع الصلاحية بمسار نصي في مجلد يكتبه المستخدم.
- لا تفريغ تلقائي للذاكرة أو الانتظار، ولا إنهاء عمليات تلقائيًا أو بالجملة.
- لا تعطيل لمهام التحديث الأمني.
- لا حذف لآخر أدلة الأعطال قبل تشخيصها.
- لا مسح دوري للمخابئ والقرص غير ممتلئ.
