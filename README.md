# مرصد الجهاز (MonitorWidget)

لوحة ويدجت وتطبيق محلي لمراقبة الجهاز وتنظيفه (Windows). الخادم Python على 127.0.0.1 والواجهة `index.html` (RTL).

## سير العمل
- الفرع `main` محمي: تغييرات عبر Pull Request فقط، مع نجاح CI.
- فروع قصيرة العمر: `feat/…`, `fix/…`, `chore/…`؛ رسائل commit بنمط Conventional Commits.
- الدمج بـ squash للحفاظ على تاريخ خطّي. الإصدارات بوسوم `vYYYY.MM.N`.
- لا تُرفع الأسرار (`.token`) ولا حالة التشغيل (قواعد البيانات، السجلات، الإعدادات) — انظر `.gitignore`.
